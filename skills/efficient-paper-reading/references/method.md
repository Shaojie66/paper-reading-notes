# 高效阅读论文方法论

本文档是 `efficient-paper-reading` 的完整方法论，源自"如何进阶学习深度学习"视频教程中关于阅读论文的核心方法。

## 1. 论文结构（标准五/六段式）

学术论文通常由以下部分构成，阅读前先在心里建立这个"地图"：

| 部分 | 作用 | 快速定位 |
| --- | --- | --- |
| 摘要 Abstract | 全文压缩，一句话讲清问题+方法+效果 | 最先读 |
| 引言 Introduction | 研究动机、已有方案不足、本文思路 | 第 2 步 |
| 相关工作 Related Work | 与前人工作的边界、增量贡献 | 第 2 步 |
| 模型/方法 Method | 具体设计、公式、架构、算法流程 | 最后精读 |
| 实验 Experiments | 设置、数据集、基线、指标、消融 | 最后精读 |
| 结论 Conclusion | 主要发现、意义、局限、未来工作 | 最先读 |

## 2. 阅读顺序（"摘要/结论先行"）

**原则：先看摘要和结论，再看引言和相关工作，最后看模型和实验。**

```
摘要 + 结论  →  引言 + 相关工作  →  模型/方法 + 实验
（建立全局）    （理清动机与边界）      （精读细节）
```

- 第一遍（粗读）：摘要+结论，约 1-2 分钟，决定"要不要继续读"。
- 第二遍（中读）：引言+相关工作，理清贡献与边界。
- 第三遍（精读）：方法+实验，关注公式、消融实验、与基线的差距。
- 目的：避免一上来陷入方法细节，先建立全局认知再深入。

## 3. 选论文（读哪些）

进阶学习时按以下顺序选论文，避免一上来啃最难/最新的：

1. **先读综述（Survey）**：快速了解一个领域的脉络、术语、主要流派与开放问题。
2. **再读经典论文**：领域内被反复引用的奠基工作，分两类——
   - **通用型**：如 Transformer、ResNet 这类改变范式的通用方法；
   - **专用型**：针对特定任务（如某检测、某生成任务）的标杆方法。
3. **用工具发现新论文**：SOTA 榜单、daily papers、智源社区等（见第 4 节）。

## 4. 推荐网站与工具

- **SOTA 榜单**：如 paperswithcode 的 leaderboard，看当前各任务最优方法是谁。
- **daily papers**：每日新论文推送/摘要，跟踪前沿动态。
- **智源社区（BAAI）**：中文学术社区，含论文解读、代码、数据集。
- 其他常用：arXiv、Google Scholar、Semantic Scholar、Paper Digest 等。

## 5. 记笔记框架（四要素）

阅读时按固定框架记录，避免"读完全忘"：

| 要素 | 记什么 | 示例 |
| --- | --- | --- |
| 问题 Problem | 论文要解决什么问题、为什么重要 | 长序列建模中自注意力 O(n²) 计算开销大 |
| 方法 Method | 核心思路、机制、关键设计 | 提出局部窗口注意力，将复杂度降为线性 |
| 效果 Results | 关键指标、与基线对比、消融结论 | 在 XX 数据集上相对 baseline 提升 X% |
| 局限 Limitations | 不足、假设、适用边界、未解决处 | 只适用于固定窗口，无法建模超长依赖 |

可扩展补充：**创新点**（相对已有工作新增什么）、**个人启发**（对自己的研究/项目的借鉴）、**下一步问题**（读完想继续探索什么）。

## 6. 使用示例

用户说"帮我读这篇论文并总结"，输出应为：

```
【一句话总结】
【问题】……
【方法】……
【效果】……（附指标）
【局限】……
【创新点】……
【个人启发/下一步】……
```
