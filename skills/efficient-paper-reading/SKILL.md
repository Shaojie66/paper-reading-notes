# Efficient Paper Reading

## Overview

基于"摘要/结论先行 + 分层精读 + 结构化记笔记"的方法，对任意输入形式的论文做高效精读，并输出固定模板的结构化笔记。适用于深度学习、AI 及各学科单篇/多篇论文的快速理解与要点提炼。

## Workflow Decision Tree

输入形式决定第一步怎么取全文：

- **PDF / 本地文件**：用 `Read` 工具读取；PDF 过短或过长用 `pages` 分段读，必要时抽图读实验部分。
- **网页链接 / arXiv / DOI**：用 `web_fetch` 获取全文；长文档分段（`pagination`）读完，不要只读摘要。
- **上传文本 / 截图**：直接解析；截图用 `Read` 读图并转写关键段。
- **多篇论文**：逐篇走完本流程，最后汇总对比（推荐用表格/对比图）。

## Reading Workflow（核心步骤）

### Step 1 — 定位结构
先确认论文包含哪些部分。标准结构：**摘要 → 引言 → 相关工作 → 模型/方法 → 实验 → 结论**。缺哪块、异常在哪块，直接标注，不要猜。

### Step 2 — 摘要与结论先行
先读**摘要**和**结论**，回答：这篇论文要解决什么问题？核心贡献是什么？主要结论/效果是什么？这一步不展开细节，只建立全局认知。

### Step 3 — 引言与相关工作
再读**引言**（研究动机、已有方案不足、本文思路）和**相关工作**（与前人工作的边界、增量贡献）。回答：它相对已有工作改进在哪？

### Step 4 — 模型与方法
最后精读**模型/方法**和**实验**：方法的具体设计、公式/架构/算法流程；实验设置、数据集、基线对比、关键指标、消融实验结论。

### Step 5 — 结构化输出笔记
按 `references/note-template.md` 的固定模板产出笔记：**问题、方法、效果、局限** 四项为骨架，可补充创新点、个人启发与下一步问题。笔记产物默认交付 Markdown 文件。

## 选论文（进阶）

当用户还在选题或问"该读哪些论文"时，见 `references/method.md` 的选论文策略：先综述 → 再经典论文（通用型/专用型）→ 用工具发现。

## 可视化输出

输出笔记时，如果论文存在结构关系（章节流程、方法框架、对比实验、方法演进），按 doubao-visualization 规范生成示意图（结构/流程/对比），文字为辅。用户明确只要文本时可省略。

## Resources

- `references/method.md` — 完整方法论：论文结构详解、阅读顺序、选论文策略、推荐工具（SOTA 榜单 / daily papers / 智源社区等）。
- `references/note-template.md` — 固定笔记模板（Markdown），直接套用产出。
- `assets/note-template.md` — 可复制的笔记空模板，用于直接交给用户填写。
