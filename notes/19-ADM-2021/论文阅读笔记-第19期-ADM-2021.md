## 一句话总结

> 扩散打不过 GAN 有两个原因：架构没人认真调过、且缺一个「牺牲多样性换保真度」的旋钮。本文把两件事分别做掉——架构消融拿到无条件 SOTA，分类器引导（用 $p_\phi(y|x_t)$ 的梯度平移采样均值，再乘一个缩放 $s$）拿到条件 SOTA，在 LSUN 与 ImageNet 64/128/256/512 全部超过同分辨率 GAN，而且训练算力更低、25 步就能打平 BigGAN-deep。

## 核心笔记

### 问题 Problem

**要解决什么**：2021 年上半年扩散模型的处境很尴尬——CIFAR-10 上已经是 SOTA（Song 等，FID 3.17），但在 LSUN、ImageNet 这类「难」数据集上仍落后 GAN；IDDPM 用两阶段上采样栈把 ImageNet 256 做到 12.26，还是不如 BigGAN-deep 的 6.95。

**作者的两个归因**（§1 明说）：
1. **架构红利不对称**。GAN 的生成器被社区打磨了五年（BigGAN 的 resblock、spectral norm、truncation 都是一轮轮调出来的），扩散模型的 U-Net 才刚被 Ho 等定型。
2. **缺少保真度旋钮**。GAN 可以用 truncation 把 latent 采样收窄，直接换「高质量、少多样性」；似然模型没有等价手段——本文附录 G 实测了温度缩放（噪声温度 / $\epsilon$ 温度两种实现），结论是**低温不但降 recall，连 precision 也降**，图变糊（Fig.12），说明「压低温度 = 聚焦众数」这个直觉在扩散里不成立。

**为什么重要**：如果扩散只能在 CIFAR 这种 32×32 的小数据集上赢，它就只是「又一个似然模型」。要在 ImageNet 256/512 上赢，必须同时解决质量和可控性——这正是本文两条腿的分工。

**指标口径的处理**（§2.2 很值得学）：作者不信任论文里报的 FID（不同实现对同一模型能差出 0.5–1），所以**统一用同一套代码、以完整训练集为参考批重算**；同时用 Precision（保真）与 Recall（覆盖）把 FID 这个混合指标拆开看，避免「变好」其实只是「变窄」。

### 方法 Method

#### 第一腿：把 U-Net 逐项消融（§3）

基线是 DDPM 的 U-Net（16×16 分辨率、单头全局注意力）。改动清单与结论：

| 改动 | 结论 |
| --- | --- |
| 加深 vs 加宽（模型大小近似不变） | 加深 FID 也能降，但**墙钟更慢**（Fig.2），故不采用；最终选加宽 |
| 注意力头数 | 1 头 14.08 → 多头更好；每头通道数越少 FID 越好，但 **64 通道/头墙钟最优**，且更像 Transformer，故选 64 |
| 多分辨率注意力（32、16、8） | 只在 16×16 做注意力不够，三层都做才显著 |
| BigGAN resblock 做上下采样 | 改善（借鉴 Song 等的 SDE 工作） |
| 残差连接缩放 $1/\sqrt{2}$ | 是清单里**唯一没带来改善**的一项，但保留（与后续工作一致） |
| AdaGN 注入 $t$ 与类别 | $\operatorname{AdaGN}(h,y)=y_s\operatorname{GroupNorm}(h)+y_b$，FID **13.06 vs 15.08**（Table 3），必须留 |

最终 ADM 规格：128 base channels（各分辨率实际 192–256）、每分辨率 2 个 resblock、多头 64 通道、注意力在 32/16/8、BigGAN 上下采样、AdaGN、数据集相关 dropout（LSUN 与 ImageNet 64 用 0.1）。

#### 第二腿：分类器引导（§4）——四步推导

**(1) 条件化反向过程**。给定无条件反向链，要把它条件在 $y$ 上只需把每一步换成

$$p_{\theta,\phi}(x_t|x_{t+1},y)=Z\,p_\theta(x_t|x_{t+1})\,p_\phi(y|x_t)$$

严格证明在附录 H（构造带标签的加噪过程 $\hat q$，证明它与 $q$ 边缘一致、且 $\hat q(y|x_t,x_{t+1})=\hat q(y|x_t)$），不是「近似技巧」。

**(2) 高斯平移**。$p_\theta(x_t|x_{t+1})=\mathcal N(\mu,\Sigma)$，对 $\log p_\phi(y|x_t)$ 在 $x_t=\mu$ 处做泰勒展开（假设其曲率远小于 $\Sigma^{-1}$，在 $T\to\infty$、$\|\Sigma\|\to0$ 时成立），得到

$$\log\big(p_\theta p_\phi\big)\approx-\tfrac12 (x_t-\mu-\Sigma g)^T\Sigma^{-1}(x_t-\mu-\Sigma g)+C,\quad g=\nabla_{x_t}\log p_\phi(y|x_t)\big|_{x_t=\mu}$$

即**只把均值从 $\mu$ 挪到 $\mu+\Sigma g$**，协方差不动。算法 1 就这么一行。

**(3) 缩放 $s$ 是什么意思**。$s\nabla_x\log p(y|x)=\nabla_x\log\frac1Z p(y|x)^s$，所以乘 $s$ 等价于用 **$p(y|x)^s$** 当条件分布：$s>1$ 把大概率进一步放大，分布变尖，采样向分类器众数集中——保真升、多样降。这一步把「调参」变成了有理论含义的操作。

**(4) DDIM 版**。确定性采样不能用上面的高斯技巧，改用 score 恒等式

$$\nabla_{x_t}\log p_\theta(x_t)=-\frac{1}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t)\;\Rightarrow\;\hat\epsilon(x_t):=\epsilon_\theta(x_t)-\sqrt{1-\bar\alpha_t}\,\nabla_{x_t}\log p_\phi(y|x_t)$$

然后原样跑 DDIM（算法 2）。所以第 18 期的采样器不用改，只改噪声预测。

**分类器怎么来**：直接拿 U-Net 的下采样主干 + 8×8 处 attention pooling，**在与扩散模型相同的噪声分布上训练**（关键：必须吃噪声图，不是干净图），加随机裁剪防过拟合。规模仅 43M（128×128）/54M（256、512）/65M（64），相对 422–559M 的生成器很轻（Table 10 里分类器只占 9–46 V100-days）。

### 效果 Results

**Table 4 一张表讲完机制**（ImageNet 256×256，2M 迭代，同一批权重只改 $s$）：

| 是否条件训练 | 引导 | $s$ | FID↓ | IS↑ | Precision↑ | Recall↑ |
| --- | --- | --- | --- | --- | --- | --- |
| 否 | 无 | — | 26.21 | 39.70 | 0.61 | 0.63 |
| 否 | 有 | 1.0 | 33.03 | 32.92 | 0.56 | 0.65 |
| 否 | 有 | 10.0 | 12.00 | 95.41 | 0.76 | 0.44 |
| 是 | 无 | — | 10.94 | 100.98 | 0.69 | 0.63 |
| 是 | 有 | 1.0 | **4.59** | 186.70 | 0.82 | 0.52 |
| 是 | 有 | 10.0 | 9.11 | 283.92 | 0.88 | 0.32 |

两个反直觉点：**$s=1$ 时无条件模型反而变差**（26.21 → 33.03），要 $s$ 足够大才起效；**$s$ 过大时 FID 回升但 IS 继续涨**（9.11 / 283.92），说明两者量的不是同一件事。

**与 GAN 正面比**（Table 5，括号内为对手）：

| 数据集 | 本文 | GAN 基线 |
| --- | --- | --- |
| LSUN Bedroom 256 | **1.90**（ADM+dropout） | 2.35（StyleGAN） |
| LSUN Horse 256 | **2.57** | 3.84（StyleGAN2） |
| LSUN Cat 256 | **5.57** | 7.25（StyleGAN2） |
| ImageNet 64 | **2.07** | 4.06（BigGAN-deep） |
| ImageNet 128 | **2.97**（ADM-G） | 6.02（BigGAN-deep） |
| ImageNet 256 | **4.59**（ADM-G） | 6.95（BigGAN-deep） |
| ImageNet 512 | **7.72**（ADM-G） | 8.43（BigGAN-deep） |
| ImageNet 256（25 步） | 5.44 | 6.95 |
| ImageNet 512（25 步） | 8.41 | 8.43 |

25 步那两行是全文最实用的结论：**25 次前向 + 25 次分类器反传就能打平 BigGAN-deep**，把第 18 期 DDIM 的加速直接兑现成「可用」。

**算力并不更贵**（Table 10，V100-days）：128×128 达到 FID 3.09 用 530 天，BigGAN-deep 用了 64–128 天但只到 6.02；256×256 达到 4.59 用 962 天，BigGAN 128–256 天到 6.95；LSUN Horse 2.95 用 116 天 vs StyleGAN2 130 天到 3.84。附录 A.2 更狠：128 模型只训 500K 迭代（约 1/8）就到 5.31，已经超过 BigGAN 的 6.02。

**与上采样互补**（Table 6）：256 上 ADM 10.94 → 加上采样 7.49 → 加引导 4.59 → 两者叠加 **3.94**；512 上 23.24 → 9.96 → 7.72 → **3.85**。引导只加在低分辨率那段。

**没记忆训练集**（附录 C）：在 Inception-V3 特征空间查最近邻，$s=1$、250 步与 $s=2.5$、25 步的样本都与训练图不重合。

### 局限 Limitations

- **采样仍然多步**。25 步 = 25 次 U-Net 前向 + 25 次分类器反向；附录 A.1 实测 256 模型优化后也只有 6.4 img/V100-s（理论 17.9），墙钟上仍不如 GAN 一步出图。作者把蒸馏（Luhman & Luhman）列为出路。
- **引导依赖标签 + 额外分类器**。没有标签数据就没有 $p_\phi(y|x_t)$；作者只提出聚类造伪标签、或训「真假判别器」两个方向，都没有实验。
- **高分辨率其实靠引导撑**。512 上无引导的 ADM FID 是 23.24（比 256 的 10.94 更差），说明 U-Net 本身在高分辨率仍不足，是 $s$ 把它拉回 7.72 的。
- **$s$ 与步数/分辨率强耦合**。Table 14：250 步最优 $s$ 在 64/128/256/512 分别是 1.0/0.5/1.0/4.0，25 步 DDIM 则是 —/1.25/2.5/9.0。换步数就要重扫，不能照搬，工程上很贵。
- **「打赢 GAN」的边界**。结论建立在 FID/IS/P/R 四个指标、4 个数据集、256/512 分辨率上；FID 本身对实现敏感（作者自己在 §2.2 强调），precision/recall 的交叉点在更高 precision 区间其实输给 BigGAN（Fig.5）。
- **引导是单向的**。它只会让分布变窄，recall 从 0.63 掉到 0.52（256，$s=1$）、0.32（$s=10$）；要「又保真又覆盖」没有旋钮。

## 扩展

- **创新点**
  1. 把「扩散落后 GAN」拆成**架构**与**可控性**两个可分别验证的原因，各自给出量化证据（Table 1–3、Fig.4–5），而不是笼统说「扩散更强」。
  2. 引导的**严格条件化证明**（附录 H）+ **可解释的缩放**（$p(y|x)^s$）——同一个 $s$ 既能解释为什么 $s=1$ 不够、也能解释为什么 $s$ 过大会掉 FID。
  3. DDIM 版引导只改 $\hat\epsilon$ 一行，**不动采样器**——与第 18 期「不动权重只换采样器」是同一种省力思路。
  4. 提供了**算力与早停**的对照（Table 7–10），把「扩散很贵」这个流行判断量化反驳了一次。
- **相关工作**：DDPM（Ho 2020）定 U-Net 与 $L_{simple}$；IDDPM（Nichol & Dhariwal 2021）给学习方差与余弦调度、也是本文的上采样栈来源；Score-SDE（Song 2021）给连续时间视角与 classifier guidance 的原始形式；DDIM（Song 2021）给确定性采样（25 步那组结果全靠它）；GAN 侧是 BigGAN/BigGAN-deep 与 StyleGAN2；似然模型侧是 VQ-VAE-2、DCTransformer、SR3。
- **个人启发**
  1. **架构消融要连时间一起报**。Fig.2 的横轴是墙钟小时，不看它就会选「加深」这个又贵又慢的配置。
  2. **引导 = 采样期的可微评分器**。这个框架可以直接搬到 CPP：把「重复访问栅格」写成 $-\log p(\text{valid})$ 式的惩罚，在去噪/扩散策略的采样步里加 $\Sigma g$，等价于推理时约束，不用重训策略。
  3. **指标要拆开报**。只报 FID 会掩盖 precision/recall 的交换；我以后写实验至少同时给 P/R 或覆盖率。
  4. **负结果值得记**：温度缩放在扩散里失效（precision 和 recall 同时掉），解释了后来为什么工业界全用 guidance 而不是 temperature。
  5. **「贵」的判断要拿算力表说话**。同一 FID 下比较 V100-days，比比较「步数」更公平。
- **下一步问题**
  1. classifier-free guidance 怎么在不训分类器的情况下复现这条 $s$ 曲线？它为什么在高 $s$ 会过饱和、把图「烧」掉？
  2. 既然 25 步需要更大的 $s$（2.5 vs 1.0），是否说明 $s$ 应该随 SNR/时间步调度，而不是全程一个常数？后来的动态阈值/rescale 是否就是这个补丁？
  3. 用 CLIP 或自监督判别器当 $p_\phi$ 会怎样？「无标签引导」的代价是偏差还是崩溃？
  4. 512 上无引导 FID 23.24，是容量、感受野还是调度的问题？LDM 的 latent 方案是唯一解吗？
  5. 把 $\Sigma g$ 平移到高维动作序列（机器人轨迹）上，低曲率假设还成立吗？协方差非对角时的近似误差有多大？

## 术语速查

| 术语 | 中文 | 一句话 |
| --- | --- | --- |
| ADM | 本文的消融后扩散模型 | 128 base channels、多头 64 通道、注意力 32/16/8、BigGAN 上下采样、AdaGN |
| Classifier guidance | 分类器引导 | 用 $\nabla_{x_t}\log p_\phi(y|x_t)$ 平移采样均值，$s$ 控制强度 |
