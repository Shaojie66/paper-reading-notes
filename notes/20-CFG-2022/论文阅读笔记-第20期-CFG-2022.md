## 基本信息

- **标题**：Classifier-Free Diffusion Guidance
- **作者/机构**：Jonathan Ho、Tim Salimans（Google Research, Brain team）
- **发表**：arXiv:2207.12598（2022-07-26）；短版本见 NeurIPS 2021 Workshop on Deep Generative Models and Downstream Applications
- **链接**：[arXiv abs](https://arxiv.org/abs/2207.12598)｜[PDF](https://arxiv.org/pdf/2207.12598)
- **难度**：中级（读前需懂 DDPM 的 $\epsilon$-预测与 score 的关系；本文把 DDIM/ADM 的采样视角换成连续时间 log-SNR）

## 一句话总结

扔掉分类器，用「条件 / 无条件两个分数之差」代替「分类器梯度」，得到同样好用的引导旋钮，且不再有「靠对抗分类器刷指标」的嫌疑。

## 核心笔记

### 问题 Problem

**现象**：ADM（第 19 期）用分类器引导把 ImageNet 256 的 FID 从 10.94 打到 4.59，代价是必须额外训一个分类器。

**三处麻烦**（作者在 §1 列得很直白）：

1. **管线变复杂**：多一个模型、多一套训练流程；
2. **不能复用现成分类器**：这个分类器必须在**带噪的** $z_\lambda$ 上训练，所以 ImageNet 预训练分类器直接拿来用是没用的；
3. **方法论上的怀疑**（这条最要紧）：把分数往 $\nabla\log p_\theta(c|z_\lambda)$ 方向推，本质就是**对着分类器做梯度攻击**；而 FID / IS 本身就是分类器指标。于是「引导让指标变好」可能只是「把分类器骗了」，甚至是「越来越像 GAN」（GAN 在这类指标上天然占优）。这两条质疑如果不排除，引导的效果就说不清。

**要解决的问题**：能不能**不用分类器**，纯生成模型自己完成引导？

### 方法 Method

#### 一、训练侧：一个 dropout 就够了

不再训第二个模型，而是**共用一个网络**：条件分支输入真实条件 $c$，无条件分支把 $c$ 换成空标记 $\varnothing$，即 $\epsilon_\theta(z_\lambda)=\epsilon_\theta(z_\lambda,c=\varnothing)$。

联合训练的方式是最朴素的：每个 batch 里**以概率 $p_{uncond}$ 随机把 $c$ 丢掉**（Algorithm 1）。损失函数一个字没改，还是 $\|\epsilon_\theta(z_\lambda,c)-\epsilon\|^2$。参数总量不变。

这里有个容易被忽略的细节：作者用的是**连续时间**（log-SNR $\lambda$）而非离散 $t$，$\lambda$ 从一个 modified hyperbolic-secant 分布采样（沿用 IDDPM 余弦调度的形状），采样时取 $u$ 均匀离散点。这样做的好处是**所有公式写成 $\lambda$ 的连续形式**，$w$ 与信噪比的关系能直接看出来。

#### 二、采样侧：两个分数做外推

$$\tilde\epsilon_\theta(z_\lambda,c)=(1+w)\,\epsilon_\theta(z_\lambda,c)-w\,\epsilon_\theta(z_\lambda,c=\varnothing)$$

$w=0$ 就是普通条件采样；$w>0$ 把「条件方向」放大、把「无条件成分」减掉。采样循环里只多算一次前向（无条件分支），其余与 DDPM/DDIM 采样完全一致（Algorithm 2 明确写了「sampling step 可换成 DDIM 等其他采样器」）。

#### 三、为什么它能替代分类器：隐式分类器（implicit classifier）

贝叶斯公式给出一个「用生成模型反推」的分类器：

$$p^i(c|z_\lambda)\propto \frac{p(z_\lambda|c)}{p(z_\lambda)}$$

它的梯度正好是**两个分数之差**：

$$\nabla_{z_\lambda}\log p^i(c|z_\lambda)=-\frac{1}{\sigma_\lambda}\big[\epsilon^*(z_\lambda,c)-\epsilon^*(z_\lambda)\big]$$

所以「用这个隐式分类器做引导」写出来就是 $\tilde\epsilon^*=(1+w)\epsilon^*(z_\lambda,c)-w\epsilon^*(z_\lambda)$——**与式 (6) 形式一模一样**。

**但作者特意强调两者不是一回事**（这是全文最锋利的一段）：$\tilde\epsilon^*$ 是用「缩放后的分类器梯度」搭起来的，而 $\tilde\epsilon_\theta$ 是用两个**神经网络输出之差**搭起来的；因为网络是无约束的，$\epsilon_\theta$ 一般**不是任何标量势的梯度**（non-conservative vector field），所以 $\tilde\epsilon_\theta$ **不存在一个对应的分类器**。推论：既然它根本不对应任何分类器，就无法被解释成「对分类器的对抗攻击」——那两条质疑自动消解。

至于是不是「越来越像 GAN」：作者的回答是「方向本身完全不像分类器梯度」（§5），并由此得出结论——**纯生成模型也能把分类器类指标（FID/IS）刷上去，这不是 GAN 的专利**。

#### 四、和上一期 ADM 的换算关系

把 ADM 的式子 $\hat\epsilon=\epsilon_\theta-s\sqrt{1-\bar\alpha_t}\nabla\log p_\phi(y|x_t)$ 与式 (6) 对照：$\epsilon_\theta(z_\lambda)-\epsilon_\theta(z_\lambda,\varnothing)\approx-\sigma_\lambda\nabla\log p^i(c|z_\lambda)$，代入后得到

$$\tilde\epsilon_\theta=\epsilon_\theta(z_\lambda,c)-w\sigma_\lambda\nabla\log p^i$$

即 **$w$ 就是第 19 期那个 $s$**，同一个旋钮，只是把「外部分类器梯度」换成「内部两个分数之差」。GLIDE 那篇后来的写法 $\hat\epsilon=\epsilon(\varnothing)+s\,(\epsilon(y)-\epsilon(\varnothing))$ 也是同一族，$s=1+w$。

#### 五、一个额外的理论解释

作者在 §5 给了一句很干净的直觉：引导**降低了样本的无条件似然、同时提高了条件似然**。分类器引导是靠"加"一个分类器梯度做到这点，无分类器引导是靠"减"一个无条件分数项做到这点——后者（用负分数项来降无条件似然）作者认为此前没人做过，可能还有别的用途。

### 效果 Results

设置：ImageNet 类条件生成，架构与超参与 ADM-G **完全相同**（少了一个分类器，实际用的容量更少）。$64\times64$ 训 400K 步、$v=0.3$；$128\times128$ 训 2.7M 步、$v=0.2$；$\lambda\in[-20,20]$；每档 $w$ 用 50,000 个样本算 FID/IS。

**Table 1（64×64，$p_{uncond}$ 取 0.1/0.2/0.5）**

| $w$ | FID | IS |
| --- | --- | --- |
| 0.0（无引导） | 1.80 / 1.80 / 2.21 | 53.71 / 52.90 / 47.61 |
| 0.1 | **1.55** / 1.62 / 1.91 | 66.11 / 64.58 / 56.10 |
| 0.3 | 3.03 / 2.93 / 2.65 | 92.80 / 88.64 / 74.92 |
| 1.0 | 12.60 / 11.21 / 9.13 | 170.1 / 158.3 / 131.1 |
| 4.0 | 26.22 / 23.84 / 21.48 | 260.2 / 249.0 / 225.1 |

对照：ADM 2.07、CDM 1.48（IS 67.95）。**最优 FID 只出现在 $w=0.1$ 这种"几乎不引导"的位置**（1.55），比 ADM 好；但 CDM 的 1.48 仍更低。

**Table 2（128×128，$T=128/256/1024$）**

| $w$ | FID（T=128/256/1024） | IS（T=128/256/1024） |
| --- | --- | --- |
| 0.0 | 8.11 / 7.27 / 7.22 | 81.5 / 82.5 / 81.5 |
| 0.3 | 3.04 / **2.43** / 2.43 | 156.1 / 158.5 / 156.0 |
| 0.4 | 3.02 / 2.49 / 2.48 | 183.0 / 183.4 / 180.9 |
| 1.0 | 7.88 / 7.86 / 7.80 | 295.3 / 298.0 / 294.6 |
| 3.0 | 19.77 / 19.77 / 19.56 | 409.2 / 407.4 / 405.7 |
| 4.0 | 21.55 / 21.53 / 21.45 | 422.3 / 421.0 / 419.1 |

对照：ADM-G 2.97；CDM 3.52 / 128.8；LOGAN 3.36 / 148.2；BigGAN-deep 5.7 / 124.5，其"最高 IS"档 25 / 253。

**三条能直接拿去用的结论**：

1. **FID 曲线是 U 形，IS 曲线单调上升**（Fig. 4–5）。$w$ 在 0.3–0.4 时 FID 最低（2.43），此时 IS 已从 82 涨到 158；$w\ge 3$ 时 IS 冲到 409–422，**同时 FID 也在同一档超过 BigGAN-deep（19.77 vs 25）**——作者称其在 FID 与 IS 上同时赢过 BigGAN-deep 的最佳 IS 截断档。
2. **最佳 FID 2.43 < ADM-G 2.97**，且用的是同一架构、还少一个分类器；作者称该结果为当时文献 SOTA。
3. **$p_{uncond}=0.5$ 全线更差，0.1 与 0.2 差不多**。含义：只需要很小一部分模型容量分给无条件任务。这和 ADM 的观察互为镜像——ADM 发现"小分类器就够用"，本文发现"少量容量就够用"，本质是同一个现象：引导需要的「对照基线」很便宜。

### 局限 Limitations

1. **每个采样步要前向两次**（条件 + 无条件）。因此**公平的速度对比是本文 $T=128$ 那列**（ADM-G 用约 256 步），而 $T=128$ 的 FID（如 $w=0.3$ 时 3.04）**反而不如 ADM-G 的 2.97**。作者自己把这个结论写进了 §4.3，没有含糊过去。
2. **$w$ 还是单向旋钮**。FID 先降后升、IS 单调升，本质仍是「拿多样性换保真度」，与第 19 期的 $s$ 同病：想要"又保真又覆盖"依然没有对应旋钮。作者在 §5 末尾专门讨论：**多样性下降在部署中可能有害**，尤其数据里本身有欠代表群体时（"欠代表群体的样本会被进一步压掉"）。
3. **强引导有可见退化**：$w=3$ 的样本出现**颜色饱和**（Fig. 3 自己就标了 "saturated colors"），$w\ge1$ 的 FID 已经崩到 7.9–26。
4. **理论上是"无保证"的**。作者老实承认：隐式分类器在生成模型设定错误（misspecified）时**可能不一致**（引 Grünwald & Langford 2007），且判别式模型通常优于生成式反推（引 Grandvalet & Bengio 2004）。**本文只有经验证据，没有保证**。
5. **实验面很窄**：只有 ImageNet $64/128$ 类条件、两个分辨率、两个指标；**没有文本条件**（text-to-image 上 CFG 才是真正封神的地方，那是 GLIDE/Imagen/LDM 后来的事），也没有 256/512。
6. **"不用训无条件模型"的替代路径没做实验**。§5 提了用 $\sum_c p(x|c)p(c)=p(x)$ 从条件分数合成无条件分数，但代价是前向次数等于类别数，作者只做讨论。
7. **架构没有为它改**。作者沿用 ADM-G 的超参（"tuned for classifier guidance, may be suboptimal"），并提到「把条件注入得晚一些」可以省掉第二次前向，留作 future work。

## 扩展

- **创新点**
  1. **把引导从"外部辅助模型"变成"模型内部的自洽操作"**——同一个网络、同一个损失，只靠条件 dropout 就同时拥有条件与无条件两种能力。这在工程上是"一行代码"，在概念上是"生成模型自带判别信息"。
  2. **用"不存在对应分类器"这一性质来回应方法论质疑**。这是很漂亮的一步：不是辩解"我没攻击分类器"，而是证明"这个方向压根不由任何分类器产生"，从而把"刷指标"的嫌疑从根上切断。
  3. **给出引导的直观解释**：降无条件似然 + 升条件似然。比"温度 / 截断"的类比更接近机制。
  4. **量化了"引导的对照基线很便宜"**：$p_{uncond}=0.1$ 就够，$0.5$ 反而更差。

- **相关工作**：ADM（Dhariwal & Nichol 2021）给分类器引导与完整配方（本文直接复用其架构）；DDPM（Ho 2020）给 $\epsilon$-预测目标；Score-SDE（Song 2021b）给连续时间与 score 视角；IDDPM（Nichol & Dhariwal 2021）给余弦调度与方差插值（本文的 $v$）；BigGAN 截断与 Glow 低温采样是"旋钮"概念的来源；CDM（Ho 2021）是同期级联扩散的对手。

- **个人启发**
  1. **"两个模型之差"是一种廉价的能力扩展手段**。不必新增模块，只要让同一个网络在"有/无输入"两种状态下都能跑，差值本身就是有用的信号。这个套路可以迁移到别的场景——比如同一策略网络在"有目标/无目标"两种输入下的输出差，天然就是一个"朝向目标"的方向场（对覆盖路径规划这类任务值得试）。
  2. **回应质疑的最好方式是改变机制，而不是加论据**。本文没有做"我们不是对抗攻击"的辩论，而是把机制换掉，让那个质疑失去对象。
  3. **作者主动写出"公平速度对比下我们输了"**（§4.3）。这种"自己给自己设最不利的比较口径"的写法，比任何 SOTA 宣称都更可信。
  4. **"U 形 FID + 单调 IS"** 这个形状要记住：以后看到任何"引导/温度/截断"类方法，先问它的最优点是靠 IS 侧还是 FID 侧、代价是几次前向。
  5. **$p_{uncond}$ 是"容量的分配比例"而非普通超参**。它同时决定"条件能力"与"对照基线质量"，扫 0.1/0.2/0.5 这个动作应该成为默认消融。

- **下一步问题**
  1. **文本条件下 CFG 还成立吗？** 类别只有离散的少数几个、可以用空标记；文本是连续高维的，"丢掉条件"丢掉的是什么？这直接指向 GLIDE / Imagen / LDM。
  2. **为什么 $w$ 与步数、分辨率强耦合**（第 19 期 Table 14 + 本文 Fig. 5 都显示曲线随 $T$ 平移）？有没有一个"最优 $w$"的解析近似？
  3. **能不能只前向一次？** 作者提"把条件注入得更晚"；实践上还有"cache 无条件分支"、"蒸馏进单次前向"两条路，后者就是 2023 年之后的 few-step 蒸馏线。
  4. **多样性怎么救回来？** 引导只压不补。有没有"补 recall"的正向旋钮（而不是靠调 $w$ 找折中）？这与第 19 期留下的同一个缺口。
  5. **欠代表群体的问题有多严重？** §5 只提了一句。若在有人群标签的数据上做 CFG，$w$ 会不会系统性削掉少数类？这其实是 AI 伦理方向可以接着做的实验。

## 术语速查

| 术语 | 含义 |
| --- | --- |
| classifier guidance 分类器引导 | 采样时把分类器对数似然的梯度加进分数，$w$ 控制强度 |
| classifier-free guidance 无分类器引导 | 用条件/无条件两个分数之差代替分类器梯度 |
| implicit classifier 隐式分类器 | $p^i(c\|z)\propto p(z\|c)/p(z)$，由生成模型反推出来的"分类器" |
| null token $\varnothing$ | 训练时用来替换真实条件的空标记，代表"无条件" |
| $p_{uncond}$ | 训练时丢弃条件的概率，本文核心训练超参 |
| non-conservative vector field 非保守向量场 | 网络输出不一定是某个标量势的梯度，故不能对应任何分类器 |
| log-SNR $\lambda$ | $\lambda=\log(\alpha_\lambda^2/\sigma_\lambda^2)$，前向过程沿 $\lambda$ 递减 |
| $v$ | 采样方差在对数空间插值的常数系数（沿用 IDDPM） |
