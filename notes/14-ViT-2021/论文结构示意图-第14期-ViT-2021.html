An Image is Worth 16×16 Words：Vision Transformer

一张图切成 196 个 16×16 patch，当作“词”送进标准 Transformer；在 3 亿张图上预训练后，精度追平最强 CNN，算力只要 1/4。
模型流程：只改输入，不改架构
除切 patch 与位置编码插值外，不向模型注入任何二维图像先验
1
输入图像 x ∈ R224×224×3
切成 14×14 = 196 个 patch（每个 16×16×3 = 768 个原始数值）
2
线性投影 E（768 → D）得到 patch embedding
等价于 kernel=16、stride=16 的卷积：每个 patch 变成一个 D 维向量，序列长度 N+1
3
拼接 [CLS] token + 可学习 1D 位置编码
z₀ = [x_class; x¹E; …; xᴺE] + E_pos；[CLS] 的输出即整图表示
4
标准 Transformer Encoder × L（B:12 / L:24 / H:32 层）
LayerNorm → Multi-Head Self-Attention（全局） → ＋残差 → LayerNorm → MLP（GELU，2 层） → ＋残差
Pre-LN 结构，与 NLP 的 Transformer 完全一致，可直接复用高效实现
5
取 [CLS] 输出 → MLP Head → 1000 类
预训练用带隐藏层的 MLP；微调时换成零初始化单层线性头（可高分辨率微调，位置编码做二维插值）
关键取舍：CNN 每层自带局部性、二维邻域、平移等变；ViT 的自注意力层是全局的，空间关系必须从数据里学——这正是"小数据输、大数据赢"的根源。

边界与代价
  • 数据门槛：优势要 14M–300M 张图；JFT-300M 为内部数据，外部难完全复现
  • 只做分类：检测/分割未验证，密集预测对分辨率更敏感
  • O(N²) 注意力：16×16 patch 尚可，高分辨率成本急升
  • 先验靠手工注入：1D 位置编码 + 换分辨率时二维插值
  • 自监督偏弱：掩码 patch 预测 79.9%，仍落后监督约 4 个点
