# 第 23 期 · Scalable Diffusion Models with Transformers（DiT）

## 基本信息

- **标题**：Scalable Diffusion Models with Transformers
- **作者/机构**：William Peebles, Saining Xie（UC Berkeley / NYU；Peebles 的工作完成于 Meta AI FAIR 实习期间）
- **发表**：ICCV 2023（arXiv:2212.09748）
- **链接**：<https://arxiv.org/abs/2212.09748> ｜ 代码 <https://github.com/facebookresearch/DiT>

## 一句话总结

> 把扩散模型的 U-Net 骨干整个换成标准 Transformer（在 VAE 潜空间的 patch 序列上工作），发现质量随前向算力（Gflops）单调改善、相关系数 −0.93，并以 118.6 Gflops 在 ImageNet 256×256 上拿到 FID 2.27，同时算力只有 ADM 的约 1/9。

## 核心笔记

### 问题 Problem

扩散模型自 DDPM 起就把 U-Net 当成默认骨干：卷积为主、ResNet block 堆叠、在低分辨率层插 self-attention。ADM 那一代只 ablation 了通道数、归一化方式这些**细节**，高层设计（"必须是 U-Net"）几乎没人动过。

于是留下三个未回答的问题：

1. U-Net 的归纳偏置（局部卷积 + 多尺度下采样）对扩散模型的质量到底**是否必需**？
2. 如果换成纯 Transformer，能不能同时继承它的 scaling 性质（深度/宽度/token 数增加时质量可预测地变好）？
3. 用什么度量"模型复杂度"？业界习惯报参数量，但参数量不含分辨率信息——同一模型在 256 和 512 上的真实成本差一个量级。

这篇论文的定位不是"再刷一个 SOTA"，而是**把骨干这件事做成一个干净的对照实验**：固定训练配方、固定数据、固定 VAE，只动架构。

### 方法 Method

**整体框架：LDM 的两阶段 + 换骨干。** 冻结 Stable Diffusion 的 f8 VAE（256×256×3 图像 → 32×32×4 潜变量，VAE 共 84M 参数），扩散过程完全在潜空间跑，只把其中的 U-Net 替换成 Transformer。所以最终系统是"卷积 VAE + Transformer DDPM"的混合体。

**1）Patchify：把潜变量变成 token 序列。** 对 $I\times I\times C$ 的潜变量按 $p\times p$ 切块，线性嵌入成 $T=(I/p)^2$ 个 $d$ 维 token，加 sine-cosine 位置编码。这里藏着全文最关键的实验杠杆：

| patch size $p$ | token 数 $T$（$I=32$） | 参数量（XL） | 前向 Gflops（XL） |
| --- | --- | --- | --- |
| 8 | 16 | 675M | 7.39 |
| 4 | 64 | 675M | 29.05 |
| 2 | 256 | 675M | 118.64 |

**参数量完全不变，只有算力变了 16 倍。** 这就把"参数"和"算力"两个变量干净地解耦了——后面所有 scaling 结论都建立在这个设计上。

**2）DiT Block：四种条件注入方式。** 扩散必须注入时间步 $t$ 和类别 $c$，四种做法在"注入位置"上分歧：

- **In-context**：把 $t$、$c$ 的 embedding 当作两个额外 token 拼进序列，最后丢掉。几乎零额外算力，但条件要和图像 token 抢注意力。
- **Cross-attention**：$t$、$c$ 单独组成长度 2 的序列，在每个 block 的 self-attention 后加一层 cross-attention。算力 +15%（137.6 Gflops），LDM 用的就是这条路。
- **adaLN**：不再学固定的 $\gamma,\beta$，而是**从 $t+c$ 的 embedding 回归**每层的 dimensionwise scale/shift，替换 LayerNorm 的仿射参数。算力最小，但所有 token 被迫共享同一个变换。
- **adaLN-Zero**：在 adaLN 基础上再回归一组 $\alpha$，作用在残差分支出口；MLP 输出**零初始化**，使每个 block 初始时是恒等映射。

零初始化的理由很直接：深残差网络从"什么都不做"开始训练最稳，这一点在 ResNet 的大 batch 训练和 U-Net 的零初始化末层里都被验证过。**这是全文最可复用的一个工程细节。**

**3）解码与训练。** 末层（adaptive）LayerNorm 后，每个 token 线性解码成 $p\times p\times 2C$ 张量（噪声预测 + 对角协方差），再 rearrange 回空间布局。训练沿用 ADM 的全套扩散超参（1000 步线性 schedule，$1\times10^{-4}\sim2\times10^{-2}$），$L_\text{simple}$ 训 $\epsilon_\theta$、全 KL 项训 $\Sigma_\theta$。

优化配方出乎意料地"素"：常数学习率 $1\times10^{-4}$、batch 256、**无 weight decay、无 warmup、无正则**，只做水平翻转，EMA 0.9999。作者明确说"超参几乎全部照搬 ADM，一个都没调"——这既是可信度的加分项，也说明结论不是调参调出来的。

**4）设计空间三轴**：patch size（2/4/8）× block 类型（上述四种）× 模型规模（S/B/L/XL，0.3–118.6 Gflops）。12 个模型，全部同一配方。

### 效果 Results

**（1）条件注入：adaLN-Zero 以最低算力赢。** DiT-XL/2、400K 步、FID-50K：

| Block 类型 | Gflops | FID-50K |
| --- | --- | --- |
| In-context | 119.4 | 35.24 |
| Cross-attention | 137.6 | 25.21 |
| adaLN | 118.6 | 26.14 |
| **adaLN-Zero** | **118.6** | **19.47** |

FID 几乎只有 in-context 的一半，且比 cross-attention 省 14% 算力。**结论：条件怎么注入，比骨干是 CNN 还是 Transformer 更影响质量**——这是全文最反直觉的一条。

**（2）缩放：Gflops 与 FID 强相关。** 12 个模型在 400K 步处，Gflops 与 FID-50K 的相关系数 **−0.93**。两个方向的证据：

- 固定 patch、加大模型：S/2 68.40 → B/2 43.47 → L/2 23.33 → XL/2 19.47。
- 固定模型、减小 patch：XL/8 106.41 → XL/4 43.01 → XL/2 19.47（算力 16 倍，FID 降 5.5 倍）。

而且**训练 loss 曲线本身**也随 Gflops 下降更快、收敛更低，与语言模型的 scaling 现象同构。这比"最终 FID 更好"更有说服力：说明算力确实在改善优化本身。

**（3）SOTA 对比（类别条件 ImageNet）：**

| 分辨率 | 模型 | FID↓ | 前向 Gflops |
| --- | --- | --- | --- |
| 256×256 | **DiT-XL/2-G (cfg 1.5)** | **2.27** | 118.6 |
| 256×256 | LDM-4-G (cfg 1.5) | 3.60 | 103.6 |
| 256×256 | ADM-G | 3.94 | 1120 |
| 256×256 | StyleGAN-XL | 2.30 | — |
| 512×512 | **DiT-XL/2-G** | **3.04** | 524.6 |
| 512×512 | ADM-G / ADM-U | 3.85 | 1983 / 2813 |

256 上比 ADM 省约 9.4 倍算力、FID 更低；512 上比 ADM-U 省 5.4 倍。**"U-Net 的归纳偏置不是必需的"这句话，是靠算力效率而不是纯 FID 站住的。**

**（4）采样算力不能替代模型算力。** 这是我认为设计得最漂亮的一个实验：DiT-L/2 用 1000 步采样（80.7 Tflops/图），FID-10K 25.9；DiT-XL/2 只用 128 步（15.2 Tflops/图），FID-10K 23.7。**大模型用 1/5 的推理算力仍然更好**。所以"小模型多采样几步"不是省算力的正路。

**（5）稳定性。** 12 个配置全程没有 loss spike，不需要 warmup 与正则——这一点对复现很关键，Transformer + 扩散此前常被担心训练不稳。

**（6）附录里一个有意思的细节**：CFG 只施加在 4 个潜变量通道中的前 3 个，scale 1.5 的效果约等于全通道 scale 1.375（2.27 vs 2.20）。作者没解释为什么，留作 open question。

### 局限 Limitations

1. **任务域极窄**：只有类别条件的 ImageNet 256/512。没有文本到图像，cross-attention 这条为文本准备的路**没有被验证**（论文只在类别标签上比过）。用 DiT 替代 Stable Diffusion 的 U-Net 是"未来工作"，不是本文结论。
2. **算力门槛高到不可复现**：XL/2 在 TPU v3-256 上 5.7 iter/s，256 分辨率训 7M 步、512 训 3M 步。作为对照，ADM 只需 2.35M 步；DiT 在同等步数下 FID 2.55，要靠 7M 步才到 2.27——**"更省算力"指的是单次前向，不是总训练成本**。这两个口径经常被混淆。
3. **Gflops 只是理论前向计数**：没算显存带宽、并行效率、TPU 实际利用率，也没有 wall-clock 对比。所以 −0.93 的相关是"同一硬件、同一配方"下的经验规律，不能当定律外推。
4. **patchify 牺牲局部性**：卷积的平移等变与局部感受野被丢掉，只能靠小 patch（更多 token）补回高频细节，而 token 数是平方增长（512 分辨率、p=2 时 1024 个 token、524.6 Gflops）。
5. **VAE 是冻结的上限**：解码器消融（2.46 / 2.30 / 2.27）差异很小，但反面说明瓶颈可能根本不在扩散骨干——如果 VAE 重建质量封顶，骨干再强也没用。论文没有讨论这个耦合。
6. **adaLN-Zero 只有消融、没有机制解释**：为什么零初始化能把 FID 从 26.14 拉到 19.47，作者没给分析（哪怕一个"梯度范数"的测量都没有）。这是经验结果，不是理解。
7. **单指标 + 单数据集**：主结论靠 FID。precision/recall 上 DiT 是 recall 更高（0.62 vs LDM-4-G 的 0.48）、precision 略低（0.83 vs 0.87）——即"覆盖模式更好、单样本保真度略让"的取舍，论文只用一句话带过。

## 扩展

### 创新点

1. **证伪"U-Net 必需"**：把扩散骨干统一到 Transformer，使扩散可以直接继承 ViT/LLM 的训练配方与并行基础设施。这是"架构统一"在生成模型上的第一次严肃落地。
2. **用 Gflops 而非参数量度量扩散复杂度**，并给出 12 个模型的完整 scaling 曲线（含 loss 曲线，不只最终 FID）。
3. **adaLN-Zero**：从 $t+c$ 回归 $\gamma,\beta,\alpha$ + 零初始化残差分支。后来 SD3、Flux、Sora 类模型全部沿用这一条件注入方式，是本文影响最大的单点设计。
4. **patch size 作为"参数固定、算力可变"的旋钮**，把 scaling 实验做得比"堆大模型"干净得多。
5. **采样算力 ≠ 模型算力**的负结果，纠正了"小模型多采样"的直觉。

### 个人启发

1. **"固定参数、只改算力"的实验设计值得直接抄。** 我在做策略网络对比时，常被"参数量不同所以不公平"卡住；DiT 的做法是固定参数量、改输入分辨率/token 数，把变量隔离出来。CPP 里可以对应"固定网络、只改地图分辨率或感受野"。
2. **条件注入是接口问题，不是骨干问题。** 我在第 22 期看到 Diffusion Policy 用 FiLM（CNN）或 cross-attn（Transformer）注入观测；DiT 的结论提示顺序应该是"先 adaLN，再 cross-attn"——因为 adaLN 更省且更强。若我要把观测条件（激光/地图）注入策略，值得先试 adaLN-Zero。
3. **零初始化残差分支可以直接拿去用。** 一行代码（末层权重置零）换来训练稳定性，成本几乎为零；扩散策略、世界模型都适用。
4. **"省算力"要分清口径。** 单次前向省 9 倍 ≠ 总训练省 9 倍（DiT 反而要多训 3 倍步数）。写论文/做汇报时必须标明是哪一个，否则容易被审稿人抓。
5. **单指标的风险。** DiT 在 FID 上赢、precision 上略输；只报 FID 会掩盖取舍。我在 CPP 实验里应同时报覆盖率、路径长度、重复覆盖率、碰撞数——这正是覆盖问题的"precision/recall"。

### 下一步问题

1. 纯像素空间的 DiT（不用 VAE）在高分辨率下 token 爆炸，多层/hierarchical Transformer 是否是唯一出路？
2. 文本条件该走 cross-attn 还是 adaLN？SD3 改用双流 MMDiT 说明单流 adaLN 对细粒度文本可能不够——差在哪一步？
3. 给定推理预算（如 20 ms），"模型 Gflops × 采样步数"的最优分配是什么？本文只证明了"采样算力不能补偿模型算力"，没给正面的分配策略。
4. 把 adaLN-Zero 搬到低维动作序列（第 22 期的 Diffusion Policy）：Transformer 在 $T_p=16$、$D=2$ 这种短序列上会不会输给 1D 卷积？token 化会不会破坏动作的连续性？
5. 能否用 DiT 生成覆盖路径？CPP 的路径是多模态的（绕左/绕右），适合分布建模，但 2D 连续控制被 patch 化后几何精度会掉——这是需要先解决的表示问题。

## 术语速查

| 术语 | 含义 |
| --- | --- |
| Patchify | 把空间张量按 $p\times p$ 切块并线性嵌入成 token 序列 |
| adaLN | adaptive layer norm：$\gamma,\beta$ 由条件 embedding 回归，而非固定参数 |
| adaLN-Zero | adaLN + 回归 $\alpha$ + 零初始化，使 block 初始为恒等映射 |
| Gflops | 前向浮点运算量（十亿次），本文的复杂度度量 |
| FID-50K | 用 5 万张生成样本算的 Fréchet Inception Distance，越低越好 |
| $L_\text{simple}$ | 简化噪声预测 MSE 损失 |
| CFG scale | 无分类器引导强度 $s$，$s=1$ 为普通采样 |
| f8 VAE | 下采样 8 倍的 VAE（256→32） |
| EMA | 指数滑动平均权重，本文 decay 0.9999 |
