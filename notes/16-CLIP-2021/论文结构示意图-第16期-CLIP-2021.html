Issue 16 · ICML 2021 · arXiv:2103.00020
CLIP：把「哪段文字配这张图」当成预训练任务
12× 训练效率 = 生成式目标（慢 3×）→ 袋词预测 → 对比目标（再快 4×）。4 亿图文对训完后，文本编码器直接「编译」出一个分类器，不做微调就能在 30+ 数据集上零样本迁移。
图像编码器：ResNet-50 → RN50x64 ／ ViT-B/32 → ViT-L/14@336px 文本编码器：63M / 12 层 / 512 宽 / 76 token batch 32,768 · 32 epoch · 128 亿张图
① 两条监督路线的差别：类别表 vs 语言
固定类别监督（ImageNet / JFT）
1,000 类 或 18,291 类 → 加一个新概念要重新标注 + 重训；输出是静态 softmax，长尾概念挤不进去。
自然语言监督（CLIP / WIT）
4 亿图文对、50 万条 query → 加一个新概念只需改写一句提示词；开放词表，无需重训。
前史并不缺想法：Mori 1999 图文检索、Joulin 2016 袋词预测、Li 2017 visual n-grams / VirTex / ICMLM / ConVIRT —— 但 Li 2017 的 ImageNet 零样本只有 11.5%（当时 SOTA 88.4%，传统 CV 方法都有 50%）。

⑦ 鲁棒性：零样本把「分布偏移鸿沟」最多缩小 75%，但一适配 ImageNet 就还回去
零样本 CLIP

⑨ 代价与边界：作者自己承认的五条
算力
追平整体 SOTA 还需约 1000× 计算，现行硬件不可行。
OOD 依旧脆
MNIST 仅 88%，输给原始像素 + 逻辑回归；以「数据够大即同分布」为赌注。
数据效率没修
128 亿张图，按 1 张/秒要 405 年。
只能选不能生成
输出被限定在给定类别集内；对比 + 生成联合训练留作未来工作。
评测口径有瑕疵
反复看完整验证集；27 个数据集与模型能力共同演化；零样本→少样本会掉点。
