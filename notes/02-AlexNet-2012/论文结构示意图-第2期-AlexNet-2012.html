本期论文 · ImageNet Classification with Deep CNNs（AlexNet, NIPS 2012）经典篇
Krizhevsky · Sutskever · Hinton（多伦多大学）。一句话主线：8 层深度 CNN + ReLU + GPU 并行 + dropout/数据增强，在 ImageNet 120 万图上把 top-5 错误率打到 15.3%，碾压亚军 26.2%，引爆深度学习革命。

每层输出后接 ReLU（max(0,x)）；Conv2/4/5 的 kernel 只与本 GPU 上层的 kernel map 相连，Conv3 跨 GPU 全连接——即论文中的双 GPU 分工。
四大关键设计（按重要性排序）

① ReLU 非线性

  • 非饱和激活，深层 CNN 收敛比 tanh 快约 6 倍
  • 没有 ReLU 就无法在当时算力下训 8 层网络

② 双 GPU 并行

  • 两张 GTX 580 3GB 各管一半 kernel
  • 仅特定层跨 GPU 通信，误差还比单 GPU 减半卷积核低 1.7%/1.2%

③ 数据增强（抗过拟合）

  • 随机裁剪 + 水平翻转：等效 2048 倍扩增
  • PCA 颜色抖动：沿 RGB 主成分扰动，模拟光照不变性，top-1 降 1%+

④ Dropout（抗过拟合）

  • FC 层 0.5 概率随机置零，抑制神经元 co-adaptation
  • 相当于指数多个模型的集成，训练时间约 ×2
成绩对比（ILSVRC-2012 图像分类）
AlexNet（7 个 CNN 集成）：top-5 错误率 15.3%　|　亚军（Fisher Vector 方案）：26.2%　|　相对最佳对手 提升约 11 个百分点。
消融结论：移除任一卷积层 top-1 掉约 2%（深度确实重要）；LRN 降 1.4%/1.2%；重叠池化降 0.4%/0.3%。
局限与后续演进
训 5–6 天 × 2 张 3GB GPU（算力硬瓶颈）· LRN 后被 Batch Normalization 取代 · 纯监督、依赖大规模标注 · 深度距人脑视觉通路还差几个数量级。
后续路线：VGG（把卷积核统一为 3×3、加深到 16 层）→ ResNet（残差连接推到 152 层）→ Transformer（注意力取代卷积）。
