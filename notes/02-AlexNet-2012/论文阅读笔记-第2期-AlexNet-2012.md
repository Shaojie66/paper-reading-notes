## 基本信息

- **标题**：ImageNet Classification with Deep Convolutional Neural Networks（AlexNet）
- **作者/机构**：Alex Krizhevsky · Ilya Sutskever · Geoffrey E. Hinton（多伦多大学）
- **发表**：NIPS 2012（Advances in Neural Information Processing Systems 25）
- **链接**：https://papers.nips.cc/paper/4824-imagenet-classification-with-deep-convolutional-neural-networks.pdf

## 一句话总结

> 在 120 万张 ImageNet 图像上训练 8 层深度 CNN，以 top-5 错误率 15.3% 赢得 ILSVRC-2012（亚军 26.2%），首次让深度卷积网络在大规模图像识别上碾压传统手工特征方法，引爆深度学习革命。

## 核心笔记

### 问题 Problem

- 真实场景中物体变化大，需要百万级标注数据；此前的标注集只有数万级（CIFAR-100、Caltech-101），撑不起通用物体识别。
- CNN 有天然归纳偏置（局部性 + 统计平稳性），但此前受 GPU 显存/算力限制，无法在高分辨率大图上大规模训练。
- 传统手工特征（SIFT / Fisher Vector）+ 线性分类器已到瓶颈。

### 方法 Method

1. **整体架构**：5 个卷积层 + 3 个全连接层（共 8 个权重层）；输入 224×224×3；FC 后接 1000-way softmax；总计约 6000 万参数、65 万神经元。
2. **ReLU 激活**：f(x)=max(0,x) 非饱和神经元，深层 CNN 收敛比 tanh 快数倍（CIFAR-10 上快约 6 倍）——不用 ReLU 根本训不动这么大的网络。
3. **双 GPU 并行**：每层 kernel 分到两张 GTX 580（各管一半 kernel），仅在特定层跨 GPU 通信；比单 GPU 减半卷积核的方案 top-1/top-5 误差还低 1.7%/1.2%。
4. **局部响应归一化（LRN）**：相邻 kernel map 竞争，辅助泛化（验证集调参 k=2, n=5, α=1e-4, β=0.75）。
5. **重叠池化**：s=2、z=3（传统 s=z=2），降过拟合，误差再降 0.4%/0.3%。
6. **数据增强**：① 随机裁剪 224×224 patch + 水平翻转（等效 2048 倍扩增）；② PCA 颜色抖动（沿 RGB 主成分方向加扰动，模拟光照不变性，top-1 降 1%+）。
7. **Dropout**：前两个 FC 层以 0.5 概率随机置零神经元，抑制神经元 co-adaptation，相当于指数多个模型集成；测试时全神经元输出 ×0.5。
8. **训练细节**：SGD batch=128，momentum=0.9，weight decay=5e-4；权重初始化 N(0, 0.01)；ReLU 层偏置初始化为 1（早期给正输入）；验证误差停滞时学习率手动 ÷10（初值 0.01，共降 3 次）；约 90 轮 × 1.2M 图像，双 GPU 训 5–6 天。

### 效果 Results

- **ILSVRC-2010**：top-1 37.5% / top-5 17.0%；此前最佳为 sparse coding 集成 47.1%/28.2%、SIFT+Fisher Vector 45.7%/25.7%。
- **ILSVRC-2012 夺冠**：7 个 CNN 集成 top-5 **15.3%**，亚军 Fisher Vector 方案 **26.2%**——相对最佳对手提升约 11 个百分点。
- **消融**：移除任一卷积层 top-1 掉约 2%（深度确实重要）；LRN 降 1.4%/1.2%；重叠池化降 0.4%/0.3%。
- **定性分析**：最后一层 4096 维特征向量按欧氏距离检索，能按**语义相似**召回同类图像（而非像素相似）——证明高层表征学到了抽象概念。

### 局限 Limitations

- 训练 5–6 天 × 2 张 3GB GPU，算力是当时硬瓶颈（网络规模受显存和训练时间限制）。
- 未尝试无监督预训练（作者预期会有帮助）。
- LRN 后来被 Batch Normalization 取代，单独看贡献有限。
- 纯监督、依赖大规模标注集；作者自己也承认网络深度距人脑视觉通路还差几个数量级。

## 扩展（可选）

- **创新点**：首次证明「大数据 + 大模型 + GPU」三者结合可行；把 ReLU、dropout、数据增强、重叠池化确立为现代 CNN 标配。
- **相关工作**：LeCun 的 LeNet（卷积+反向传播）、Nair & Hinton 2010（ReLU）、Hinton et al. 2012（dropout）。
- **个人启发**：① 第 1 期提到的「深度视觉用于自动驾驶/机器人」正是此文落地的感知栈前身；② 覆盖路径规划的视觉感知层普遍以这种 ImageNet 预训练骨干（backbone）为起点；③ 学术英语：NIPS 经典论文行文范例——结构紧凑、消融实验交代得很清楚。
