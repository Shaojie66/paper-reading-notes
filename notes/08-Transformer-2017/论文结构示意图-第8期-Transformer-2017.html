本期论文 · Attention Is All You Need（NeurIPS 2017）范式·Transformer
Vaswani / Shazeer / Parmar / Uszkoreit / Jones / Gomez / Kaiser / Polosukhin。一句话主线：去掉 RNN 和卷积，只用注意力——缩放点积注意力 + 多头 + 位置编码，全并行训练。英德 28.4 BLEU（超所有含集成结果 2+）、英法单模型 41.8 BLEU（成本不到 SOTA 的 1/4）。现代大模型（BERT/GPT）的架构源头。
问题：三个痛点

RNN 串行瓶颈

  • h_t 依赖 h_{t-1}，样本内无法并行
  • 序列越长，批内并行受内存限制越严重

远距离依赖难学

  • CNN 连接两位置需 O(log_k n) 层堆叠，路径长
  • RNN 最大路径长 O(n)

attention 只是配角

  • 此前 attention 总是搭配 RNN 使用
  • 没人证明「只用 attention」就够了
方法：Transformer 架构（图 1 示意）
Encoder ×6
① 多头自注意力
② position-wise FFN
每子层：残差 + LayerNorm
输入 = 词嵌入 + 位置编码
⇄
Decoder ×6
① 掩码多头自注意力（保自回归）
② encoder-decoder 注意力（Q←decoder, KV←encoder）
③ position-wise FFN
输出右移一位 + 掩码禁止看未来 → 线性层 + softmax
核心公式：
Attention(Q,K,V) = softmax( QKT / √dk ) V  （缩放点积）
MultiHead(Q,K,V) = Concat(head1…headh) WO，  headi = Attention(QWiQ, KWiK, VWiV)
FFN(x) = max(0, xW1+b1)W2+b2   PE(pos,2i)=sin(pos/100002i/d), PE(pos,2i+1)=cos(...)
h=8 头、d_model=512、d_ff=2048、N=6；除以 √d_k 防止点积过大把 softmax 推入梯度极小区；位置编码让模型感知顺序。

消融要点（Table 3，EN-DE dev）
· 头数：单头 24.9（-0.9），头过多也下降 → 多头必要但非越多越好
· 减小 dk 伤质量 → 兼容性函数本身难学
· 大模型更好、dropout 显著防过拟合；学习位置嵌入 ≈ 正弦位置编码（25.7 vs 25.8）
局限与演进
局限：O(n²) 自注意力对长序列成本高；无归纳偏置、位置全靠注入（后由 RoPE/ALiBi 改进）；生成仍自回归顺序化。
演进路线：Bahdanau 加法注意力（第 7 期）→ 本文缩放点积 + 多头（去 RNN）→ BERT（双向预训练） / GPT（自回归预训练）→ 大语言模型。
