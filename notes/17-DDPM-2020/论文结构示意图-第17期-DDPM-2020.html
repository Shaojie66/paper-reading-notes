两条链：固定加噪的前向 q，学出来的反向 pθ

方法·骨架
x₀真实图
→
x₁微噪
→
…逐步加噪
→
xt-1ᾱ 递减
→
xtᾱ 递减
→
xT≈ 纯噪声
↓ 前向 q：无参数，T = 1000，β 从 1e-4 线性升到 0.02，末端 DKL ≈ 1e-5 bits/dim
↑ 反向 pθ：从 N(0, I) 出发，每步由 U-Net 预测噪声并去掉一点
q(x_t | x_{t-1}) = N( x_t ; √(1-β_t)·x_{t-1} , β_t I ) ← 前向（固定）
q(x_t | x_0) = N( x_t ; √ᾱ_t·x_0 , (1-ᾱ_t) I ) ← 任意 t 可闭式直采（训练的前提）
p_θ(x_{t-1} | x_t) = N( x_{t-1} ; μ_θ(x_t, t) , σ_t² I ) ← 反向（只学均值，方差固定）

关键在第二行：训练时随机取 t 就能一步得到 xt，不必真的展开 t 步链——这是「可训练」而非「只能空想」的技术前提。

03

训练循环只有一句话：让它把刚加进去的噪声猜回来

方法·核心

① 采一张图 x₀

随机取样本，线性缩放到 [-1, 1]，保证与 N(0, I) 先验同尺度。

② 随机取 t、随机取 ε

t ~ U{1…1000}，ε ~ N(0, I)。一步合成加噪图，无需求解链。

③ 让网络回归 ε

输入 √ᾱtx₀ + √(1-ᾱt)ε 与时间 t，输出「我认为加了多少噪声」。

④ 一次梯度步

整个训练只有一次前向一次反向，不展开 1000 步——比自回归逐像素便宜。

L_simple(θ) = E_{t,x₀,ε} ‖ ε − ε_θ( √ᾱ_t·x₀ + √(1-ᾱ_t)·ε , t ) ‖²

相比标准变分下界，L_simple 丢掉了 1/σt² 的权重：小 t（噪声弱、任务易）的项被自动降权，梯度集中到大 t 的难例。作者把这个「副作用」当作正向收益，实验也确实更好。

04

三种等价的输出目标，效果差 4 倍

方法·消融

预测后验均值 μ̃、预测噪声 ε、预测原图 x₀，在数学上都只是 pθ(xt-1|xt) 的不同重参数化；但在同一 U-Net、同一数据下，优化难度完全不同。

输出目标损失IS ↑FID ↓结论
μ̃（后验均值）完整变分下界 L7.2823.69可用，但差
μ̃无权重 MSE——训练不稳
ε（噪声）完整变分下界 L7.6713.51与 μ̃ 持平
εL_simple（去权重）9.463.17最好
x₀（原图）———作者称早期质量更差

同一架构下 FID 23.69 → 13.51 → 3.17：收益来自目标函数与参数化的配合，不是加模块、不是加算力。学习对角方差 Σθ 的两行均训崩，所以方差只能固定。

06

它把采样过程读成了「渐进有损压缩」

解释

把 L₁+…+LT 当码率、L₀ 当失真：最好的 CIFAR 模型 rate 1.78 bits/dim、distortion 1.97 bits/dim（RMSE 0.95 / 255）。率-失真曲线的形状说明——一半以上码长花在人眼看不见的细节上。

收到 1000 步rate 1.776 · RMSE 0.95
完整图像
900 步rate 0.12 · RMSE 12.0
细节仍缺
700 步rate 0.029 · RMSE 24.4
500 步rate 0.007 · RMSE 38.0
300 步rate 0.0008 · RMSE 54.2
100 步rate 0 · RMSE 67.6
只剩大轮廓

生成过程也对应这个顺序：大尺度特征先出现，细节最后补齐（Fig.6/10）。在 CelebA-HQ 上固定同一中间隐变量多次采样，t=750 的样本已共享性别、发色、姿态等高层属性（Fig.7），说明中间隐变量确实编码了可解释属性。作者进一步证明：把扩散步数设成数据维度、前向改成逐坐标掩码，这套框架退化为自回归模型——扩散 = 一种无法用坐标重排表达的广义 bit 顺序的自回归。

作者也承认：Algorithm 3/4 的「发送端」依赖 minimal random coding，对高维数据不可行，所以压缩只是 proof of concept，不是可用系统。

17DDPM · 生成范式

前 16 期把「判别式」这一支铺完了：CNN → 序列 → Attention → 视觉/语言编码器 → 图文对齐。DDPM 补的是生成式这一支的第一块基石——同一年代的另一条主线（自回归语言模型）在第 6、8、15 期已覆盖，而「从噪声里长出图像」的路线从此成为 ADLCV 与后续多模态生成（含 Stable Diffusion 系）的共同底座。

下一步读什么

DDIM（2020，20–50 步采样）→ Improved DDPM（2021，学方差 + cosine schedule）→ Classifier Guidance（2021）→ LDM / Stable Diffusion（2022）。

可迁移到自己的项目

「换参数化 > 换架构」（FID 13.51→3.17）；按难度重加权（对应 CPP 里给边界决策更高权重）；粗到细生成 ↔ 分层覆盖规划。

避坑引用 FID 3.17 时必须注明「训练集口径」；引用 NLL 时不要与 GAN 比（GAN 无似然）；引用采样速度时区分 32² 与 256²。
