# 第 24 期 · Learning to Recharge: UAV Coverage Path Planning through Deep Reinforcement Learning

## 一句话总结
> 把「电池不够、必须中途落地充电、却仍要覆盖指定区域」的 UAV 覆盖路径规划写成 POMDP，用 PPO + 三层动作掩码 + 折扣因子调度 + 位置历史层，训练一个从地图直接出动作的策略；在 12 张 32×32–50×50 栅格地图上比自建贪心启发式少走 24%–31% 的步数，训练全程零违规。

## 核心笔记

### 问题 Problem
覆盖路径规划（CPP, Coverage Path Planning）本身是 NP-hard：经典做法是先把环境分解成细胞（cellular decomposition），每个细胞里用往返扫描（boustrophedon）覆盖，再决定细胞的访问顺序。但真实的小型四旋翼有一个绕不开的限制——**电池只够飞一小段**，大区域必须「飞一段 → 降落 → 充电 → 再起飞」反复多次。这时充电行程本身就是覆盖策略的一部分，是跨整个任务时段的长程决策，而不是覆盖完再补一段返航。

论文把难点拆成三条：
1. **充电时机与覆盖分解耦合**：哪些目标格子留给下一趟、这一趟从哪个降落区起降，必须提前算清，否则会剩下小片目标白跑一趟。
2. **目标区域可以不等于整个自由空间**：只覆盖部分 patch，且目标格可能落在禁飞区（NFZ）里，只能贴着边缘用视场（FoV, Field of View）扫。
3. **观测是部分可观的**：低矮建筑可以飞越但会遮挡视场，高层建筑等同于禁飞区，智能体看到的地图与实际可覆盖区域不一致。

现有工作里，非 DRL 的分解 / 图搜索 / 元启发式方法大多不含充电约束；DRL 侧的 UAV CPP 又很少把地图直接喂给网络，也很少处理「一次任务要飞好几趟」的情形。本文的前作（ICAR 2021、IROS 2020）做了地图输入与变功率约束，但同样不含充电。

### 方法 Method
#### 1 环境建模：栅格世界 + 7 个原子动作
三张布尔图描述环境：障碍 $B$、降落区 $L$、禁飞区 $Z$。电池不建模成能量，而是直接记为**「还能走几步」** $b_t$：$b_{\max}=100$，一次充电动作 $b_c=2$，初始电量在 $[\beta b_{\max}, b_{\max}]$ 随机（$\beta=0.5$）。

动作空间 $A=\{\text{east},\text{north},\text{west},\text{south},\text{take off},\text{land},\text{charge}\}$。约束很硬：只有落地才能充电、只有电量未满才能充、只有飞行中且站在降落区格子上才能降落（公式 6）。状态约束两条：不能进禁飞区（7a），电量不能为空除非已落地（7b）。

覆盖目标集合 $C_t$ 每步按视场更新：
$$\mathcal{C}_{t+1}=\{\forall x\in\mathcal{C}_t \mid \neg v(p_{t+1},x,B)\}$$ 即从下一位置能看到、且未被障碍挡住的目标格被移除。

#### 2 两个目标函数：不带充电 vs 带充电
- **不带充电**（前作用的设定）：$l_0=false$，从降落区上方以随机电量起飞，目标是 $\min |C_T|$，$T$ 定义为首次落地的时刻。
- **带充电**（本文主角）：$l_0=true$，从降落区半电以上出发，目标是
$$\min T \quad \text{s.t.}\quad \mathcal{C}_T=\{\}\ \wedge\ l_T$$
即目标全部覆盖且已降落。时段长度取决于策略本身，比前者长一个量级，也更难。

#### 3 三层动作掩码：把「安全」写进动作空间
这是全文最值得抄的设计，三层递进：

| 层级 | 定义 | 含义 |
| --- | --- | --- |
| valid | 只满足动作前置条件（公式 6） | 屏蔽「飞行中再起飞」这类无定义动作 |
| immediate | 在 valid 上再排除一步后进入禁飞区 | 屏蔽立刻违规 |
| invariant | 在 immediate 上再要求 $d_L(p')\le b_t-1$ | 屏蔽「走完这步回不了降落区」的死局 |

$d_L$ 由一张到最近降落区的距离图 $D$ 提供，$D$ 用递归定义：降落区为 1，禁飞区为 $\infty$，其余为 $1+\min\{\text{四邻居}\}$。掩码的实现方式是把不可行动作的 logits 置 $-\infty$ 再 softmax——不需要额外的安全层，策略本身就只会在可行集上分布。

#### 4 奖励与折扣因子调度：先学会做完，再学会做快
理想奖励只有每步一个惩罚，但智能体从零开始几乎不可能随机撞到终止条件，所以加了覆盖奖励：
$$r_t=r_c\left(|C_t|-|C_{t+1}|\right)-r_m,\qquad r_c=0.01,\ r_m=0.02$$
（覆盖一格约抵消两步的代价。）

问题在于折扣因子：$\gamma=1$ 时 return $=r_c|C_0|-r_m T$，只有缩短 $T$ 才能最大化，理论上最优，但值估计会炸；$\gamma<1$ 又让「先多覆盖」压过「整体更快」，变成贪心。作者的办法是让 $\gamma$ 在训练中爬升：
$$\gamma=1-(1-\gamma_0)\gamma_r^{\,s/\gamma_s},\quad \gamma_0=0.99,\ \gamma_r=0.1,\ \gamma_s=2\times10^7$$
即从 0.99 渐进到 0.999，前 2000 万步学会「把任务做完」，之后逐步优化「做得快」。

#### 5 位置历史层：用观测而不是奖励破解「充电循环」
充电能力带来一个副作用：状态可以复现。飞一圈没覆盖到任何新格、回到同一个降落区充电，观测与之前完全相同——确定性策略会原地死循环（文中 Fig.2 两种：反复「起飞-降落-充电一步」，或来回飞直到安全掩码逼它返航）。

作者没有加「重复惩罚」，而是给观测加一层历史：
$$H_{t+1,i,j}=\begin{cases}1,&\text{当前位置}\\ \alpha H_{t,i,j},&\text{其他}\end{cases},\quad \alpha=0.99$$
位置被踩过就留痕、随时间衰减。这样即使回到同一格，观测也不一样，循环自然被打破。奖励函数因此保持「干净」，最优策略的定义也没被改动。

#### 6 全局-局部观测 + 网络
地图先以智能体为中心补边到 $2m-1$，然后分两支：
- **全局地图**：按 $g=3$ 下采样，给长程规划一个压缩视野；
- **局部地图**：裁中心 $l=17$ 的窗口，给精细避障与视场判断。

两支各 5 通道（降落区 / 禁飞区 / 障碍 / 剩余目标 / 位置历史），再加 2 个标量（归一化电量、落地标志）。网络结构：$1\times1$ 卷积升到 32 通道 → 4 次「$2\times3\times3$ 卷积 + $2\times2$ 最大池化」→ 每支得 512 维 → 拼标量 → 3 层 256 宽全连接。actor 与 critic 同构，各约 5M 参数；PPO（clip $\epsilon=0.1$，TD($\lambda=0.8$)），总交互 $1.2\times10^8$ 步。

#### 7 基线：自建贪心启发式
文献方法无法直接套到「带充电 + 多层约束」的设定，作者自建 model-based 贪心：落地就充满再起飞；没目标就飞最近降落区降落；否则找「最近的可达、且能看见目标」的格子飞过去；若不存在，则飞向离目标最近的降落区充电。指标用
$$\mathrm{RPD}=\frac{\text{steps}_{\text{agent}}-\text{steps}_{\text{heuristic}}}{\text{steps}_{\text{heuristic}}}$$
负值表示比贪心更少步数。

### 效果 Results
**1）掩码消融（Fig.5，Multi3 智能体，1.2 亿步）**

| 掩码 | 行为 |
| --- | --- |
| 无掩码 | 卡在两个局部最优：要么永远趴着不动，要么飞出去覆盖一趟却不返航 |
| valid | 崩溃率 10–20%，覆盖率 1.2 亿步后仍很低，**从未完成过任务** |
| immediate | 能学到 90–95% 成功率，但剩余场景以撞毁告终 |
| invariant | **最快学会、成功率接近 100%、训练全程零违规** |

一层掩码的差别比换网络结构大得多：同样算力，无掩码完全学不出，不变量掩码千万步量级就开始解任务。

**2）折扣调度（Fig.6）**：常数 $\gamma$ 越大，学会解任务越晚（$\gamma=1.0$ 在 1.2 亿步内始终没稳定解出）；调度版比常数 0.99 和 0.999 的最终步数都低，且早期就有优势。作者最终选 $\gamma_0=0.99$ / $\gamma_s=2\times10^7$。

**3）位置历史（Table III，每图 1024 个随机场景）**：分布内（Suburban+Castle+TUM）确定性基线解出率 95.5% → 加历史后 98.9%，RPD 从 $-16.5\%$ 改善到 $-17.3\%$；最难的 Border 地图从 9.3% 提到 27.5%。对照实验里换成等维度的**随机层**也能破循环（说明「观测变化」确实有效），但 RPD 从 $-16.3\%$ 掉到 $-11.3\%$——因为随机噪声只是打散了行为，没有记住走过的路。

**4）主结果（Table IV，12 张地图）**
- 专用智能体在自己训练的地图上：100% 解出，RPD 分别为 Suburban $-28.7\%$、Castle $-23.7\%$、TUM $-26.5\%$、Cal $-30.7\%$、Border $-28.6\%$——**比贪心少 24%–31% 步**。
- 多图智能体：Multi3 在训练过的三张图上是 $-15.4\%$ / $-18.3\%$ / $-19.2\%$；Multi10 是 $-8.9\%$ / $-10.7\%$ / $-7.1\%$。多图换来泛化、代价是每张图的专精度。
- 未见地图：Multi10 在 Border 只有 35% 解出（$+21.5\%$ RPD），Multi3 27.5%；专用智能体跨地图基本 0–10%。**泛化是本文最明显的短板**，作者也把 one-shot / few-shot 泛化留作后续工作。

**5）机制上的收获——多架次分解是学出来的**：Fig.7 在 Manhattan 地图（把 $b_{\max}$ 调到 75，几乎不可能一趟扫完）上，智能体 166 步 vs 贪心 266 步，另一场景 225 步 vs 382 步。贪心的毛病是把小片目标留到下一趟、白跑一趟；智能体预先算好「这一趟能扫多少」，把目标切成几次往返，且每次充电点位不同。

**6）敏感度**：目标区只加一小块，整条轨迹就完全不同（Fig.8 两个仅差一个绿色小目标区的场景，走法分别从上方和下方绕）——策略对目标分布有相当强的过拟合。

### 局限 Limitations
- **纯栅格仿真，能量过于抽象**。电量 = 剩余步数，「充电」是瞬间 +2，没有爬升、悬停、风、载荷的真实能耗模型，也没有充电耗时与时序约束。
- **单机单任务**。没有多机协同、没有动态障碍，也没有通信约束。
- **未见地图泛化差**。最难的 Border 只解出约三分之一，专用策略跨图基本失效。
- **基线偏弱**。只比了自建贪心，既没和经典「boustrophedon 分解 + TSP 排序」比，也没和其他 DRL 方法比。$-28\%$ 是相对启发式的读数，不是相对最优的读数。
- **训练昂贵**。每个配置 3 个种子、每个约 4 天 A100，全文十几个配置，个人复现成本很高。
- **技巧之间强耦合**。作者在掩码消融里专门提到：没有不变量掩码时，折扣调度反而**有害**——因为撞毁惩罚相对便宜，随着 $\gamma$ 上升「撞了更划算」。这说明调度不是万能插件，必须和约束处理配套。
- **指标只算步数**。失败率高的地图（Border）直接不报 RPD，等于回避了部分失败样本。

## 扩展（可选）
- **创新点**：① 把充电行程并入覆盖策略统一优化，而不是「先覆盖完再考虑电量」；② 三层动作掩码把合法性 / 一步安全 / 不变量安全（可返航）分开，并给出可计算的 $D$ 图判据；③ 折扣因子调度解决「先学会做完再学会做快」的两难；④ 位置历史层用观测而非奖励破解充电导致的状态循环，是可复用的通用 trick；⑤ 开源 gym 风格的 `uavSim` 框架、12 张地图与训练好的模型。
- **相关工作**：Galceran & Carreras 2013 综述（[第 9 期](../09-CPPSurvey-2013/论文阅读笔记-第9期-CPPSurvey-2013.md)）给出分解 + 排序的经典框架；同作者 ICAR 2021 / IROS 2020 提供 global-local 观测与变功率约束但无充电；Jonnarth et al. 2023（[第 13 期](../13-CPPDRL-2023/论文阅读笔记-第13期-CPPDRL-2023.md)）被本文列为「未知环境 + 地图输入 + 局部感知」的对照；方法侧依赖 PPO、invalid action masking（Huang & Ontañón 2022）与 safe RL 综述。
- **个人启发**：① 带硬约束的 RL 任务，先把「不可行动作」算清楚，收益常大于调网络；② 「masking + $\gamma$ 调度 + 历史观测」是可迁移到巡检、数据采集等长时段任务的标准配方；③ 破循环优先改观测而不是加惩罚，否则最优策略的定义被悄悄改掉；④ 做 CPP 的规范基线应是「分解 + 排序」，拿学习式方法和一个贪心比会高估收益；⑤ 复现前先估算力，课程项目建议 32×32 小图 + 少量配置验证思路。
- **下一步问题**：① 换成真实能耗（悬停 / 爬升 / 风）后还能不能收敛？② 多机版本里充电位变成排队资源，掩码要不要升格为「排队 + 预留」？③ 未见地图从 35% 往上推，程序化地图生成、域随机化、测试时自适应哪个最有效？④ 与 boustrophedon + TSP 做公平对比，在什么地图结构上学习式方法才真有优势？⑤ 位置历史层能否换成显式 episodic memory 或覆盖计数先验，减少对 $\alpha$ 的依赖？

## 术语速查
| 术语 | 含义 |
| --- | --- |
| CPP | Coverage Path Planning，覆盖路径规划 |
| FoV | Field of View，视场，决定一格目标是否被「看到」 |
| NFZ | No-Fly Zone，禁飞区；高层障碍也等价于禁飞 |
| POMDP | 部分可观测马尔可夫决策过程 |
| Action masking | 动作掩码，把不可行动作 logits 置 $-\infty$ |
| RPD | Relative Percentage Deviation，相对基线的步数偏差 |
| $d_L$ | 到最近降落区的距离，用于不变量安全判据 |
