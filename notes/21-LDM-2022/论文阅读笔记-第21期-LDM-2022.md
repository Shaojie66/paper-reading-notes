## 一句话总结

像素空间不是扩散模型唯一的家。先训一个只负责“看起来像”的自编码器，把 256×256×3 按 $f=4$ 压成 64×64×3，再在这个潜空间里做 DDPM——训练和采样便宜了 2.7 倍以上，质量反而更高。条件注入不再靠拼接，而是用交叉注意力把任意 token 序列接进 UNet 中间层，于是文本生图、布局生图、超分、修补、语义合成共用一个骨架。

## 核心笔记

### 问题 Problem

到 2021 年底，扩散模型已经是 ImageNet 类条件生成和超分的 SOTA，但代价极不友好：

- **训练**：最强的 ADM 要 150–1000 个 V100 days。原因是每一次梯度计算都在**高维 RGB 像素**上做，而像素里绝大部分比特是不可感知的高频细节。
- **采样**：50k 个样本在单张 A100 上要跑约 5 天（25–1000 步顺序前向，每步一次全网络）。
- **容量错配**：似然模型天生 mode-covering，会把容量花在建模肉眼看不见的细节上。DDPM 的 reweighted 目标只是“少采几步前面的噪声”，并没有改变“仍在像素空间算梯度”这个事实。

已有的两级方案（VQGAN、DALL-E）想用“先压缩再建先验”绕开这个问题，但被自回归先验逼进死角：压缩得狠 → 信息损失、重建变糊；压缩得轻 → AR 序列爆炸、参数上十亿。而且 AR 把潜空间拉成一维序列，丢掉了图像 z 本来有的二维结构。

顺带一个被忽略的缺口：扩散的条件一直是“类标签”或“低分图”，**文本、布局这类 token 型条件几乎没人做**。而能把任意条件接进来，才是“生成模型”变成“可用工具”的分界线。

### 方法 Method

全文的方法可以拆成两个正交的决定，加一个接口。

**决定一：把压缩和生成彻底分开（§3.1）**

第一阶段只训自编码器：编码器 $z=\mathcal{E}(x)$，解码器 $\tilde x=\mathcal{D}(z)$，下采样 $f=H/h$，实验中扫 $f\in\{2^m\}$。训练目标是**感知损失 + patch 判别器**，而不是纯 $L_2$——保证重建被约束在图像流形上、不出现 $L_1/L_2$ 特有的模糊。潜空间的正则有两种：`KL-reg`（对标准正态加轻微 KL，像 VAE）与 `VQ-reg`（解码器前放量化层，等价于把 VQGAN 的量化吸收进解码器）。

关键取舍写在 Fig. 2 里：数字图像的大部分比特是“感知冗余”，而语义信息集中在低维流形上。所以正确做法不是让生成模型去啃高频，而是**用一个轻压缩把感知冗余先剥掉**，只留语义压缩给扩散模型。

**决定二：在潜空间上重写 DDPM 目标（§3.2）**

$$\mathcal{L}_{LDM}:=\mathbb{E}_{\mathcal{E}(x),\;\epsilon\sim\mathcal{N}(0,1),\;t}\Big[\|\epsilon-\epsilon_\theta(z_t,t)\|_2^2\Big]$$

形式与 DDPM 的 $\mathcal{L}_{DM}$ 一模一样，只是 $x_t$ 换成了 $z_t$。三个工程上的好处：

1. 训练时 $z_t$ 由 $\mathcal{E}$ 一次前向得到（前向过程固定，不需要反传），采样后 $\mathcal{D}$ 一次解码——**图像只在两端各过一次**。
2. 骨干仍是 time-conditional UNet，直接继承 DDPM/ADM 的空间归纳偏置，所以**不需要 VQGAN 那种激进压缩**，$f=4$ 就能保住细节。
3. 自编码器只训一次，可复用于所有下游 DM——这正是“通用压缩模型”的价值。

**接口：交叉注意力做条件（§3.3）**

给 UNet 的中间层插入 cross-attention，把任意模态的 $y$ 先过一个领域专用编码器 $\tau_\theta$ 投影成 $\tau_\theta(y)\in\mathbb{R}^{M\times d_\tau}$：

$$Q=W_Q^{(i)}\cdot\varphi_i(z_t),\quad K=W_K^{(i)}\cdot\tau_\theta(y),\quad V=W_V^{(i)}\cdot\tau_\theta(y)$$
$$\text{Attention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^\top}{\sqrt d}\right)V$$

训练目标相应变为 $\mathcal{L}_{LDM}=\mathbb{E}\big[\|\epsilon-\epsilon_\theta(z_t,t,\tau_\theta(y))\|_2^2\big]$，$\tau_\theta$ 与 $\epsilon_\theta$ **联合优化**。

这个接口的漂亮之处在于 $\tau_\theta$ 可以换：文本时是 BERT tokenizer + 无 mask 的 transformer（输出 $1280$ 维），空间对齐条件（超分低分图、mask、语义图）时干脆是**恒等映射 + 直接拼接**。一套 UNet，两种接法，五种任务。

### 效果 Results

**1）$f$ 有一个明确甜点（Fig. 6 / Fig. 7 / Tab. 13）**

固定单张 A100、固定步数、固定参数量扫 $f$：

| $f$ | 潜空间形状（256² 输入） | 表现 |
| --- | --- | --- |
| 1（像素基线） | 256×256×3 | 训练极慢，2M 步后 FID 与 LDM-8 差 **38** |
| 2 | 128×128×2 | 仍偏慢 |
| **4** | **64×64×3** | 甜点，ImageNet 类条件主用 |
| **8** | **32×32×4** | 甜点，文本/无条件常用 |
| 16 | 16×16×8 | 可用，细节开始吃亏 |
| 32 | 8×8×32 | 几步之后就停滞：感知压缩过头、信息已丢 |

重建质量上，$f=4$ 的 PSNR **27.4** / R-FID **0.58**，明显好于 DALL-E 的 $f=8$（22.8 / 32.01）和 VQGAN 的 $f=16$（19.9 / 4.98）——这就是“不用激进压缩”换来的上限（Fig. 1）。

**2）无条件生成（Tab. 1，256²）**

| 数据集 | LDM | 主要对手 | 判断 |
| --- | --- | --- | --- |
| CelebA-HQ | **5.11**（500 DDIM） | LSGM 7.22、UDM 7.16、PGGAN 8.0 | 新 SOTA，且赢过联合训练的 LSGM |
| FFHQ | 4.98（200 步） | StyleGAN 4.16、ProjectedGAN 3.08 | 输给 GAN，但 Precision/Recall 更均衡（0.73/0.50） |
| LSUN-Churches | 4.02 | StyleGAN2 3.86、ProjectedGAN 1.59 | 略输 |
| LSUN-Bedrooms | 2.95 | ADM 1.90 | 输 FID，但**参数约一半、训练资源 1/4** |

一个值得记住的模式：LDM 在 FID 上不一定赢 GAN，但在 **Recall**（覆盖率）上系统性更好——这是似然目标的性质，也是后面“扩散取代 GAN”的真正理由之一。

**3）类条件 ImageNet，与第 19/20 期正面对撞（Tab. 3）**

| 方法 | FID↓ | IS↑ | 参数 | 备注 |
| --- | --- | --- | --- | --- |
| BigGAN-deep | 6.95 | 203.6 | 340M | GAN 基线 |
| ADM | 10.94 | 100.98 | 554M | 无条件引导前 |
| ADM-G | 4.59 | 186.7 | 608M | 分类器引导（第 19 期） |
| LDM-4 | 10.56 | 103.49 | **400M** | 不加引导 |
| **LDM-4-G** | **3.60** | **247.67** | **400M** | c.f.g. $s=1.5$（第 20 期） |

同一个 256² 赛道：ADM-G 4.59/186.7（608M）→ LDM-4-G 3.60/247.67（400M）。**参数少 1/3、FID 再降 0.99、IS 再涨 61**。这不是新方法，而是第 20 期的 CFG 在潜空间上被放大了一次。

**4）文本生图，CFG 是决定性的那一步（Tab. 2，MS-COCO 256）**

| 方法 | FID↓ | IS↑ | 参数 |
| --- | --- | --- | --- |
| CogView | 27.10 | 18.20 | 4B |
| LAFITE | 26.94 | 26.02 | — |
| GLIDE | 12.24 | — | 6B（c.f.g. $s=3$） |
| Make-A-Scene | 11.84 | — | 4B（c.f.g. $s=5$） |
| LDM-KL-8 | 23.31 | 20.03 | 1.45B |
| **LDM-KL-8-G** | **12.63** | **30.29** | **1.45B**（c.f.g. $s=1.5$） |

只用 $s=1.5$ 就把 FID 从 23.31 砍到 12.63、IS 从 20 涨到 30——**一个标量换了 10.7 个 FID 点**。代价是参数只有 GLIDE 的 1/4，FID 仍略高 0.39，但 IS 反超，说明它更“锐”而非更“准”。

**5）超分与修补：通用性，不是单项冠军**

- 超分 64→256（Tab. 5）：LDM-4 FID **2.8**（val 特征）/ 4.8（train 特征），169M；SR3 是 5.2，625M。但 **PSNR 24.4 vs 26.4**，纯回归能到 27.9（更糊）。用户研究：对 GT 偏好 30.4% vs 像素版 16.0%；二选一 70.6% vs 29.4%。
- 修补 Places 512²（Tab. 7）：big + finetune FID **1.50**（全样本）/ **9.39**（40–50% 大面积遮挡的硬样本）；LaMa 2.21 / 12.0。用户研究 21.0% vs 13.6%、68.1% vs 31.9%。
- 吞吐（Tab. 6）：同等参数下 LDM-4 相对像素版训练快 ~2.9×、采样快 ~3.7×，FID 改善至少 1.6×（20.66 → 6.66）。

**6）卷积式外推分辨率**

空间对齐条件（语义图、低分图、mask）用拼接注入时，模型可以在 $256^2$ 上训练、在 $512\times1024$ 甚至百万像素上卷积式采样（Fig. 9、Fig. 12）。前提是**潜空间要按分量标准差重标定**（§D.1）——这一步不做，外推会直接崩。配上 CFG 还能直接生成 $>256^2$ 的文本条件图（Fig. 13）。

### 局限 Limitations

1. **省了算力，没省步数**：顺序采样依旧比 GAN 慢一个量级。潜空间让每步更便宜，但步数没变（论文用 250 步 DDIM；即使用 DDIM 也要 100–250 步）。
2. **重建误差是硬天花板**：$f=4$ 的 R-FID 0.58 / PSNR 27.4 已经是“感知无损”，但对**像素级精度**敏感的任务会卡住。作者自己承认超分模型“已经在这方面受限”——LDM-SR 的 PSNR/SSIM 全线输给回归和 SR3。
3. **两阶段引入新的手调维度**：$f$ 要扫，KL/VQ 要选，潜空间还要 rescale。这些超参不是理论推出来的，是实验试出来的。
4. **文本条件只是“能打平”**：FID 12.63 仍略高于 GLIDE 的 12.24；而且这是 1.45B 模型 + MS-COCO 这种“短标题”分布，复杂长 prompt 的组合性（属性绑定、计数）论文完全没测。
5. **潜空间统计特性脆弱**：卷积外推依赖 SNR 重标定，属于“必须照做但没解释清楚”的工程细节。
6. **社会影响只提问题不给方案**：deepfake（原作者点名“女性受影响不成比例”）、训练数据被反演、偏见复制，都停在“重要研究问题”。

## 扩展

### 创新点

1. **把“感知压缩”与“语义压缩”拆成两级**，并给出 $f$ 的定量甜点（4–8），把上一代两阶段方法的两难（压太狠 vs 压不够）变成一条可扫的曲线。
2. **潜空间用“固定”的预训练自编码器**，而不是像 LSGM 那样联合训练——从而绕开“重建能力 vs 生成能力”的加权折衷，这是本文相对同期工作最锋利的一刀。
3. **交叉注意力作为通用条件接口**：$\tau_\theta$ 可插拔（文本用 transformer、空间条件用恒等+拼接），一套 UNet 覆盖 text / layout / class / SR / inpainting。
4. **卷积式分辨率外推**：$256^2$ 训练，$512\times1024$ 出图。
5. **工程与开源**：代码 + 权重直接放出，成为 Stable Diffusion 的地基（SD 1.x 只是换 $f=8$、换 CLIP 文本编码器、并把 CFG 做成默认）。

### 相关工作（这条主线的位置）

- DDPM（第 17 期）给了目标函数与 UNet 骨架；DDIM（第 18 期）给了少步采样，本文全程用 DDIM 采样器；ADM（第 19 期）给了架构消融与分类器引导；CFG（第 20 期）给了“不要分类器”的引导——**本文正是把这四块拼成一个可用系统**。
- 对照系：VQGAN / DALL-E 是“离散潜空间 + 自回归”，LSGM 是“潜空间 + 联合训练”，本文是“连续潜空间 + 固定自编码器 + 卷积骨干”。
- 下游：GLIDE（文本引导修补）、Imagen（级联像素扩散）、SD 系列（本文的直接产品化）。

### 个人启发（对照 CPP / 机器人方向）

1. **“先压缩到感知等价空间，再学语义”可以搬到栅格地图**。做大地图覆盖路径规划时，若把扩散策略直接放在 $512^2$ 栅格上，成本会像 LDM-1 一样爆炸；先训一个“地图自编码器”把栅格压成 $64^2$ 潜表示，再在潜空间上做条件扩散，与本文的账是同构的。代价同样明确：**重建误差会变成规划精度的下限**（对应 $f=4$ 那条 R-FID 0.58 的地板）。
2. **条件接口要按“是否空间对齐”来选**。语言指令、路点序列 → 交叉注意力；已覆盖区域栅格、障碍 mask、当前位姿热图 → 拼接。本文把这两条路径都跑通了，等于免费给了我们一个设计决策表。
3. **CFG 的 $s$ 是真实系统里最便宜的质量旋钮**：23.31→12.63 只用 $s=1.5$。但它在 CPP 场景有副作用——$s$ 抬高质量的同时压掉多样性，而多样性正是“多条覆盖方案备选”的来源，压掉可能直接降低对未知环境的鲁棒性。
4. **算力账值得记**：单张 A100、178K 步、batch 1200，就能在 ImageNet 256 上拿 FID 3.60。这解释了 2022 年后开源社区为何能迅速复现——实验室级别的资源是够的。
5. **伦理段落的写法值得学**：不写“我们反对滥用”这种空话，而是点名“deepfake 对女性的影响不成比例”并给引用，再承认“训练数据反演在图像 DM 上还不清楚”。这是 AI 伦理写作的正确姿势——具体、可核查、留白。

### 下一步问题

1. $f$ 能不能不靠 sweep？重建 R-FID 与最终生成 FID 之间是否存在可预测的映射，从而先验地选 $f$？
2. 两阶段的上限耦合有多强？把第一阶段换成更强的 tokenizer（连续 tokenizer / SDXL 的 VAE），生成 FID 会线性改善还是很快撞墙？R-FID 0.58 在 ImageNet 上折合多少 FID？
3. 潜空间 rescaling（§D.1）为什么对卷积外推是生死线？z 上的 SNR 定义如何影响 CFG 的有效 $s$ 区间？
4. 交叉注意力插在哪几层，对**组合性**（属性绑定、数量、空间关系）影响多大？论文只给了“中间层”，这批消融是 2023 年后 compositional generation 那条线的起点。
5. 若接到 CPP：潜空间条件扩散 + 覆盖约束，用拼接注入已覆盖栅格，能否在 $512^2$ 级地图上做到实时？实时性瓶颈会落在采样步数还是解码器？

## 术语速查

| 术语 | 含义 |
| --- | --- |
| LDM | Latent Diffusion Model，在自编码器潜空间里训练的扩散模型 |
| perceptual compression | 感知压缩：只去掉不可感知的高频细节，几乎不改语义 |
| semantic compression | 语义压缩：真正学数据的概念与组合结构 |
| $f$ | 下采样因子，$f=H/h$；$f=4$ 表示长宽各缩 4 倍 |
| KL-reg / VQ-reg | 潜空间正则：轻微 KL 拉向标准正态 / 量化层（置于解码器内） |
| cross-attention | 交叉注意力，$Q$ 来自 UNet 特征、$K/V$ 来自条件 $\tau_\theta(y)$ |
| $\tau_\theta$ | 领域专用条件编码器（文本用 transformer，空间条件用恒等） |
| c.f.g. | classifier-free guidance（第 20 期），本文记作 $s$ |
| convolutional sampling | 卷积式采样，在比训练分辨率更大的画布上滑窗去噪 |
| R-FID | 重建 FID，衡量第一阶段自编码器的重建质量 |
